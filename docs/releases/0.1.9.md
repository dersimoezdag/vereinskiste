# Vereinskiste 0.1.9

- Der Upgrade-Test berücksichtigt alle vorhandenen Migrationen und prüft die vollständige Schemahistorie.
- Neue Migrationen erfordern keine manuelle Anpassung einer zweiten Dateiliste oder Migrationsanzahl mehr.
- Enthält die Funktionen von 0.1.8: gemeinsame Schrittanzeige und Live-Fortschritt bei Updates.

Das Paket wird mit dem bestehenden Ed25519-Schlüssel signiert.
Vor dem Update Datenbank, Konfiguration und private Dateien extern sichern.
