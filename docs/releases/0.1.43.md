# Vereinskiste 0.1.43

- **Updatequelle umgestellt auf Forgejo**: Die Updateprüfung und der signierte Download laufen ab dieser Version über `https://forgejo.lexframe.de/LexFrame/vereinskiste` (Releases-API und Release-Assets). GitHub bleibt als Download-Host in der Allowlist, damit Installationen bis 0.1.42 dieses Release noch von GitHub laden können.
- Dieses Release wird letztmalig auf GitHub veröffentlicht; ab dem nächsten Release ist Forgejo der alleinige Release-Ort.
- Einstellungsseite, Fehlermeldungen und Doku nennen Forgejo als Quelle.

Das Paket wird mit dem bestehenden Ed25519-Schlüssel signiert.
Vor dem Update Datenbank, Konfiguration und private Dateien extern sichern.
