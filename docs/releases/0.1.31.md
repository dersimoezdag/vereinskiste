# Vereinskiste 0.1.31

- Gültige Einladungslinks zu Mitgliedsanträgen können mit entsprechender Schreibberechtigung widerrufen werden. Der Widerruf wird protokolliert.
- Widerrufene Links sind sofort gesperrt, auch wenn sie zuvor per Passwort entsperrt wurden.
- Abgelaufene und widerrufene Einladungslinks werden standardmäßig ausgeblendet und können über einen Filter angezeigt werden.

Datenbankmigration 0026 ergänzt den Widerrufszeitpunkt für Einladungslinks.
