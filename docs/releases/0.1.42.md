# Vereinskiste 0.1.42

- Fehlgeschlagene automatische Updates zeigen die technische Fehlermeldung direkt auf der Fortschrittsseite an.
- Die Diagnose wird zusätzlich im privaten Verzeichnis des Updatevorgangs gespeichert.

Für die Diagnose eines Updates von 0.1.40 auf 0.1.42 muss die geänderte Update-Komponente bereits in der laufenden Installation vorhanden sein. Ein neues Release allein kann den Fehler eines alten Updaters nicht rückwirkend sichtbar machen.
