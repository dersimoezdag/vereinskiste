# Vereinskiste 0.1.32

- Einstellungen besitzen eine eigene linke Navigation mit thematisch geordneten Bereichen und passenden Tabs.
- Der Wechsel zwischen Anwendung und Einstellungen erfolgt mit einer sanften Transition. „Zurück zur Anwendung“ führt zur letzten Anwendungsseite samt Filtern. Reduzierte Bewegung und die mobile Navigation werden berücksichtigt.
- Die SEPA-Vorgabe steht in einem eigenen Tab neben dem Antragsbuilder.
- Einladungslinks können für eine einstellbare Anzahl von Mitgliedsanträgen verwendet werden; Standard ist ein Antrag. Die bisherige Nutzung wird angezeigt.
- Mitgliedsanträge und Einladungslinks haben getrennte Seiten unter Mitglieder.
- Die Update-Seite enthält Herstellerinformationen zu Dersim Özdag mit GitHub-Profil und Repository-Link.

Keine neue Datenbankmigration erforderlich.
