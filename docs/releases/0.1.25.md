# Vereinskiste 0.1.25

- Neue Oberfläche auf Basis von Tailwind CSS: einheitliche Farben, Schriften (Geist) und Bausteine für Schaltflächen, Eingabefelder, Tabellen und Bereiche. Tabler wird nicht mehr mitgeliefert.
- Hilfe-Tooltips bleiben nach einem Klick geöffnet und schließen per Klick außerhalb, Escape oder Scrollen.
- Dialoge schließen nur noch bei einem Klick auf den Hintergrund, nicht mehr beim Herausziehen einer Textauswahl.
- Menüs werden erst angezeigt, wenn sie richtig positioniert sind; Browser ohne Popover-Unterstützung werden berücksichtigt.
- Kleinere Korrekturen an den Diagrammen der Übersicht.

Keine neue Datenbankmigration erforderlich.
