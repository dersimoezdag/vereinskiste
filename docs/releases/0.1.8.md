# Vereinskiste 0.1.8

- Einrichtung und automatische Aktualisierung nutzen dieselbe Schrittanzeige.
- Die Update-Phasen werden während der Installation live nachgeführt; ein fehlgeschlagener
  Schritt wird rot markiert.
- Netzwerkfehler und Zeitüberschreitungen während der Aktualisierung werden automatisch
  wiederholt, danach kann die Installation manuell fortgesetzt werden.
- Der Hinweis „Aktualisierung läuft“ bleibt nach einem abgeschlossenen oder abgebrochenen
  Update nicht mehr stehen.
- Nach einem Fehler bei der Einrichtung springt der Assistent zum letzten Schritt;
  ungültige Felder in verborgenen Schritten werden automatisch angezeigt.
- Alle Texte der Einrichtungs- und Updateseiten liegen im Textwörterbuch.

Das vollständige Paket wird mit dem bestehenden Ed25519-Schlüssel signiert.
ZIP, Prüfsumme, Manifest und Signatur gehören zusammen; der private Schlüssel
ist nicht im Paket enthalten.

Vor dem Update Datenbank, Konfiguration und private Dateien extern sichern.
Ab installiertem 0.1.5 kann die Aktualisierung unter Einstellungen → Version &
Updates automatisch erfolgen. Ältere Installationen benötigen einen manuellen
Upload unter Erhaltung von `app/config` und `app/storage` sowie die Datenbankaktualisierung.
