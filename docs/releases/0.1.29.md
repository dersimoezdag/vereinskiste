# Vereinskiste 0.1.29

- Vereinsnamen können bis zu 300 Zeichen lang sein. Das einheitliche Limit gilt für die Vereinsdaten und die Ersteinrichtung.
- Straße und Hausnummer stehen in den Vereins- und Kontaktdaten nebeneinander in einer Zeile.
- Beim Bearbeiten von Erklärungen stehen Texteditor und Vorschau untereinander, auch auf großen Bildschirmen.

Keine neue Datenbankmigration erforderlich.
