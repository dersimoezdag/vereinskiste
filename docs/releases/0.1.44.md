# Vereinskiste 0.1.44

- **Auslagen als ausbezahlt markieren** mit Auszahlungsweg: PayPal (E-Mail-Adresse des Empfängers), Überweisung (IBAN mit Prüfsumme, BIC optional) oder Bar, plus Auswahl des zahlenden Kontos.
- **Optionale Gegenzeichnung des Empfängers** (Einstellungen → Zahlungsfreigabe): Ist sie aktiv und hat der Empfänger ein verknüpftes Benutzerkonto, zeichnet er die Auszahlung auf einer eigenen Seite mit Unterschrift (Ort + PNG, unveränderlich gespeichert) gegen. Ohne verknüpftes Konto wird die Auszahlung ohne Gegenzeichnung endgültig.
- Das erste Release, das ausschließlich über Forgejo Actions gebaut und veröffentlicht wird (GitHub veröffentlicht keine Releases mehr; die Updatequelle zeigt seit 0.1.43 auf Forgejo).

Das Paket wird mit dem bestehenden Ed25519-Schlüssel signiert.
Vor dem Update Datenbank, Konfiguration und private Dateien extern sichern.
