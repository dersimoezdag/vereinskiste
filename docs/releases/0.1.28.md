# Vereinskiste 0.1.28

- Unter Mitgliedsanträge können über das Dreipunktmenü Testantragslinks erstellt werden. Sie durchlaufen das vollständige Formular mit sichtbarem Test-Hinweis, ohne Anträge, Mitglieder oder E-Mails anzulegen, und sind mehrfach nutzbar.
- Deutsche Postleitzahlen sind auf fünf Zeichen begrenzt und werden auch serverseitig geprüft. Nach Eingabe einer vollständigen PLZ liefert Komoot Photon passende Ortsvorschläge; die manuelle Ortseingabe bleibt möglich.
- E-Mail-Felder schlagen ab dem @ passende Anbieter vor. Diese Vorschläge werden lokal im Browser erzeugt; eigene Domains bleiben möglich.
- Verbesserte Formularschritte, Datums- und Unterschriftseingaben sowie eine überarbeitete Abschlussseite mit Konfetti.

Enthält die Datenbankmigration 0024 für Testantragslinks. Nach dem Update die Datenbankaktualisierung ausführen.
