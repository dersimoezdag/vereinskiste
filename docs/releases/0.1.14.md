# Vereinskiste 0.1.14

- Der Hell/Dunkel-Schalter wird direkt vom früh geladenen Theme-Skript gesteuert und funktioniert unabhängig von der übrigen Seiteninitialisierung.
- Wiederholtes Umschalten funktioniert auch bei blockiertem Browser-Speicher; die Auswahl bleibt während der geöffneten Seite erhalten.
- Klicks auf die Schalter-Symbole und erst später gerenderte Schalter werden unterstützt.

Keine zusätzliche Datenbankmigration. Die bestehende Umschalter-Darstellung bleibt erhalten.
